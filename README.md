# AI-Powered Student Career Hub

An enterprise-level career platform connecting university students with recruiters via AI-driven insights.

## Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS, Shadcn UI, Framer Motion, Recharts.
- **Backend:** Node.js, Express, TypeScript, Socket.io, JWT.
- **Database:** MongoDB (Mongoose).
- **AI:** OpenAI GPT-4o.
- **Storage:** Cloudinary.

## Installation

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas account
- OpenAI API Key

### Backend Setup
1. `cd server`
2. `npm install`
3. Create `.env` from `.env.example`
4. `npm run dev`

### Frontend Setup
1. `cd client`
2. `npm install`
3. `npm run dev`

## Deployment
- **API:** Deploy to Render/Railway.
- **Frontend:** Deploy to Vercel.
- **DB:** MongoDB Atlas.

## Key Features
- **AI Resume Analysis:** Real-time ATS scoring.
- **Mock Interviews:** Voice/Text based AI interviews.
- **Real-time Chat:** Persistent messaging between roles.
- **Job Recommendations:** ML-based matching.
